# Personal Projects

Selected projects from my **MSc Business Analytics** at Rotterdam School of Management (RSM), Erasmus University. They cover predictive modelling, customer analytics, textual analysis and a small product build. I'm interested in quantitative finance, text-as-data methods, and Python/R data workflows.

## Projects

| Project | What it is | Main tools |
|---|---|---|
| [**Thesis**: AI narratives in earnings calls](Thesis/Data%20%26%20Program) | Master's thesis on how AI-related language in S&P 100 earnings calls relates to stock market reactions, using a dual-channel (hype vs. substance) framework. Includes the full pipeline from text processing to panel regressions. | Python, R, Loughran-McDonald dictionary, panel regression |
| [**Customer Analytics**](Customer%20Analytics) | Customer lifetime value, segmentation, acquisition and retention analysis of about 875k customers of a food-delivery chain ("Restaurant Chain X"). | Python, `lifetimes` (BG/NBD, Gamma-Gamma), pandas, SciPy |
| [**FinTech**: BNPL Safeguard](FinTech) | MVP that shows consumers and lenders a person's total Buy Now Pay Later obligations across providers, built from confirmation emails with an LLM extraction step and a rule-based reliability score. Includes a browser extension for checkout. | Node.js, Express, Next.js, Gmail API, Gemini |
| [**Business Analytics Workshop**](Business%20Analytics%20Workshop) | Data cleaning, normalisation and position-specific regression models of football player market value for a Dutch professional club, including scraped Transfermarkt data. | Python, regression, web scraping |

Each folder has its own README with setup instructions and results.

## A note on data

Some of these projects use data I don't own (licensed financial data, client data, course data). Where the licence or the client doesn't allow redistribution, the data is left out, and the folder's README says what is needed to reproduce the results.
